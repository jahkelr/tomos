How TOMOS ships automations

The products below were built for operators who need clarity, observability, and maintainability—not lab demos. They share deployment patterns, authentication, and monitoring so you can run them side-by-side without glue work.

  • Shared conventions: Python 3.11, Alembic migrations, Prometheus-ready metrics, and deterministic fallbacks for CI.
  • Job-ready: Docker Compose targets spin up APIs, workers, Postgres, Redis, and Chroma with one command.
  • Governed access: `.env.example` files document the secrets you need; API keys, queues, and schema live in version control.

Automation 01

Tenant Context Service (TCS)

Multi-tenant content memory that crawls your approved sources, canonicalizes the knowledge graph, and exposes retrieval APIs for downstream apps.

  • Crawls websites, RSS feeds, and static docs, then embeds and normalizes every chunk per tenant.
  • Hybrid BM25 + vector search with API-key authentication, canonicalized entities, and metrics at `/metrics`.
  • Docker Compose stack boots API, worker, Postgres, Redis, and Chroma with `make up` plus optional demo seed.
View TCS docs

Automation 02

Product Description Engine (PDE)

Takes product imagery + metadata, blends it with TCS-derived tone, and delivers SEO-ready copy across channels.

  • Uses OpenCLIP/BLIP (or deterministic fallbacks) to describe images before handing context to your preferred LLM.
  • Supports synchronous `/pde/generate` calls plus async ingestion queues for bulk batches over Redis/RQ.
  • `make seed` provisions a demo tenant, brand profile, and sample product so stakeholders can review outputs fast.
View PDE docs

Automation 03

TOMOS Doc Intelligence (TDI)

Answers policy and operations questions with citations by ingesting PDFs, DOCX, HTML, Markdown, and raw text.

  • Parses unstructured docs, chunks + embeds them into Chroma namespaces, and stores metadata in Postgres.
  • Ships `/tdi/ask`, summarize, and draft endpoints plus feedback capture so SMEs can grade outputs.
  • Worker + API split keeps ingestion responsive, and `make seed` loads sample policies for instant validation.
View TDI docs

Automation 04

Messaging Service

Lightweight UI + API for editing templates and delivering personalized email/SMS campaigns without introducing yet another marketing suite.

  • Template editor with live previews, CSV list ingestion, deduplication, and a persisted fallback mailing list.
  • `/send` delivers Gmail-backed personalized emails, `/send-text` logs SMS payloads for future provider wiring.
  • FastAPI UI served at `/` with health checks for orchestration plus `.env` hooks for SMTP credentials.
